## 硬件系统形态

- 机架：一个标准化的金属柜子，用来把多台服务器、网络设备、存储等集中装在一起。一台普通服务器可能是 1U、2U 或 4U 高，直接滑进机柜的导轨上。“U”是机架高度单位，1U = 4.445 厘米

- 传统单台服务器：最基础的单位，按“台”买卖，适合预算有限或起步阶段的企业自己组网。

- 超节点整机柜：比普通机架耦合更紧密，通过高速总线把几十上百张卡“焊”成一个逻辑上的超级计算机，追求极致的协同效率。

- 定制化集群：不只是卖硬件，而是根据业务需求提供从设计、组网到调优的“交钥匙”工程，属于深度定制的系统交付。

### 口径说明与结论

- **“50 tok/s/用户”是交互性目标值，不是 p99。** 若严格按 p99 尾延迟卡 SLA，吞吐会再低约 10–30%，不能直接当作 p99 结论使用。
- **表 1 取的是每个平台在该点的最优引擎 + 精度**，所以会出现“单机 B200（FP4）单卡吞吐反而高于整柜 GB200（FP8）”的反直觉结果——这是 FP4 约 2x 增益叠加单机免 EP 通信开销造成的。整柜的优势要到更低交互目标（如 125 tok/s/用户）或更长上下文 / 更大 MoE 时才显现，届时 GB200 对 B200 可达约 4.4x/卡。
- **单卡持有成本 AMD 最低**（MI300X $0.95/卡·h），**单位 token 成本 NVIDIA Blackwell 最低**（B200 $0.10/1M token）。两者不矛盾：AMD 胜在单价便宜，NVIDIA 胜在每卡吞吐高。
- **H100 已不划算**：$4.38/1M token 约为 B200 的 44 倍，除非已有存量资产。
- **整柜 vs 单机**：GB300 NVL72 每卡成本（$2.31）仅比 B300（$2.26）贵约 2%，但柜内互联与 20 TB 池化显存是单机给不了的，大 MoE / 长上下文仍应选整柜。
- **国产价格缺口**：昇腾 / 寒武纪没有公开的 $/卡·h 与同口径 token 成本，采购价仅为市场估算，不能直接用于 TCO 测算。
