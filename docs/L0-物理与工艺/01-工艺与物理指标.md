# 工艺与物理指标：良率、链路与散热

> **这一层在讲什么。** [00-物理与工艺](00-物理与工艺.md) 讲清楚了工艺节点、先进封装、SerDes、供电与散热这些物理约束；这篇回答**怎么量它们、以及它们如何变成选型约束**。
>
> **读法。** 只想知道"概念"，读完 00 就够；要做供应与成本评估、要判断某个方案在物理上是否成立，再往下读这篇。
>
> **和 L1 的分工**：L1 的指标是**性能规格**（能跑多快），这一层的指标是**可行性与成本**（能不能造、造多少、多贵、能不能散热）。**两层要一起看才能做选型**——L1 告诉你上限，这一层告诉你上限能不能兑现。

## 一、工艺指标：别看节点数字

**"3nm / 2nm"不是可比的指标**（见 [00 的第一节](00-物理与工艺.md)）。真正该看的是这几个：

| 指标 | 含义 | 为什么有用 |
|---|---|---|
| **晶体管密度** | 单位面积晶体管数（或标准的逻辑/SRAM 密度） | 直接决定"同样面积能放多少东西" |
| **SRAM 位单元面积** | 单位 SRAM 面积 | **决定片上缓存划不划算**——它缩小得比逻辑慢 |
| **性能/功耗曲线** | 同频率下的功耗，或同功耗下的频率 | 决定能效天花板 |
| **掩模尺寸限制** | 单次曝光能造的最大面积 | 决定"要不要拆分芯粒" |

**一个实务判断**：**比较两个代际时，比的应该是"在目标功耗下能达到的性能"，而不是节点名。** 先进节点在低功耗区间优势明显，但在高功耗/高频区间的优势会被显著压缩——**这对加速卡这种追求峰值吞吐的设备尤其重要**。

**SRAM 密度这条特别值得记**：它解释了为什么芯片设计普遍在"加片上缓存"和"用 HBM"之间反复权衡——**当 SRAM 面积缩小放缓，片上缓存的单位容量成本相对上升，外置高带宽内存的吸引力就相对变大**。

**这条不是推测，有公开数据支撑**——它可能是整层里最反直觉的一个事实：

| 数据点 | 内容 | 说明 |
|---|---|---|
| **Intel 4 的 SRAM** | 高密度位单元约 0.0240 µm²，相对上代**仅缩放约 0.77–0.81 倍** | 而同期**逻辑库缩放约 2 倍** |
| **TSMC N2 的 SRAM** | 高密度位单元约 **0.021 µm²**，密度约 **38.1 Mb/mm²**，相对上代**仅 ×1.1** | 同一代节点的逻辑仍在明显缩小 |

**"1.1 倍"这个数字本身就是最硬的证据**：新一代工艺的逻辑密度可以大幅提升，**但 SRAM 几乎原地踏步**。所以"换新节点就能便宜地加更多片上缓存"这个假设**已经不成立**。

**这条事实向上传播得很远**：它解释了为什么厂商在架构上越来越依赖"芯粒化 + 外置高带宽内存"，而不是"把缓存堆在片上"——**不是因为片上缓存不好，而是因为它在经济上越来越不划算**。这与 [L1 的存储金字塔](../L1-芯片与硬件/00-芯片与硬件.md)是同一枚硬币的两面。

**一个实务判断**：**比较两个代际时，比的应该是"在目标功耗下能达到的性能"，而不是节点名。** 先进节点在低功耗区间优势明显，但在高功耗/高频区间的优势会被显著压缩——**这对加速卡这种追求峰值吞吐的设备尤其重要**。

## 二、良率：这一层最有价值的一组公式

**良率是芯粒路线存在的全部理由**，而它可以用公式算——这是这一层少有的可以定量推导的部分。

### 2.1 基本关系

芯片制造有随机缺陷，缺陷密度（单位面积缺陷数）记为 D，芯片面积记为 A。**最简模型**（假设缺陷完全随机、互不相关）给出：

```
良率 Y = e^(−A·D)          （Poisson 模型）
```

**这个式子最有用的地方是指数项**：面积翻倍，良率不是减半，而是**按指数下降**。

### 2.2 更接近现实的模型：幂律而非指数

**这里必须修正一个流行的说法。**"大芯片良率随面积**指数**下降"**只在 Poisson 假设下成立**——而 Poisson 假设（缺陷完全随机独立）在真实制造中通常不成立：缺陷往往**成簇出现**。

描述这一现象的经典模型是**负二项分布模型**，它引入一个**聚集因子 α**：

```
良率 Y = (1 + A·D/α)^(−α)          负二项模型（业界最常用）
```

**它的两个极限恰好说明了这个模型的意义**：

| 聚集因子 | 退化为什么 | 物理含义 |
|---|---|---|
| **α → ∞** | Poisson 模型 `e^(−A·D)` | 缺陷完全随机独立、不成簇 |
| **α = 1** | Seeds 模型 | 聚集程度较强 |

**所以结论要这样表述才准确**：

- 在 **Poisson 假设**下，良率随面积**指数**下降；
- 在**负二项模型**下，良率随面积是**幂律**下降——**指数下降只是 α → ∞ 的特例**。

**为什么这个区别重要**：两个模型给出的**数值差异很大**。用指数模型估算大芯片成本会**显著高估损失**（因为忽略了成簇效应带来的"部分好处"），从而可能得出"必须拆芯粒"的错误结论。**成簇实际上是有利的**——缺陷集中在一小片，会让那一小片整块报废，而不是让整片芯片都受牵连。

> 历史上这几个模型是有先后的：早期的 Poisson、Murphy 等人提出的三角/均匀模型，到后来引入聚集因子的负二项模型（相关文献发表于 1980 年代的半导体制造期刊）。**教材把它们并列讲述，实际工程中用负二项的最多。**

### 2.3 用这些公式算芯粒的账

```
大芯片的良率  →  很低（面积大）
拆成 N 块小芯粒  →  每块良率高
                 → 但需要"封装良率"这一项
最终成本 ≈ 各芯粒成本 + 封装成本 + 已知合格芯片的测试成本
```

**芯粒什么时候划算**：当"大芯片良率损失"大于"封装成本 + 测试成本 + 芯粒间接口开销"时。**这就是为什么芯粒不是所有产品都做**——小芯片本来良率就高，拆它没有意义。

### 2.4 良率还有个连带指标：测试覆盖率

**已知合格芯片（KGD）**是芯粒路线的关键前提：**必须在封装前把坏的芯粒筛掉**，否则一块坏芯粒毁掉整个封装。所以：

- **测试覆盖率**（能筛出多少比例的缺陷）直接决定封装良率；
- **测试成本**随覆盖率要求非线性上升；
- 无法在封装前测试的部分（如芯粒间的连接）只能在封装后测，**这部分损失是纯损耗**。

> **但 KGD 本身没有统一定义**——这一点有官方公告明确承认：**"KGD 定义不清，含义因制造商与用例而异"**，不同的军用标准里有的定义它、有的干脆不定义。所以**"我们的芯粒是 KGD"这句话本身不足以说明测试到了什么程度**，必须追问**测试覆盖了哪些失效模式**。
>
> 这也解释了为什么芯粒路线里"测试策略"是个独立的技术课题：**KGD 不是一个能买到的现成结论，而是一套要自己设计的流程**。

> **一个估算口径**：先进封装产品的综合良率可以近似为「各芯粒良率之积 × 封装工艺良率」。**乘积效应是残酷的**——五块芯粒各 95% 良率，乘起来只有 77%。这是芯粒路线常被低估的成本项。

## 三、链路指标：从 lane 速率到有效带宽

### 3.1 一个必须会算的换算

规格页给的通常是**每 lane 的信号速率**（单位 GT/s，即每秒十亿次传输）。**它不等于数据带宽**，因为：

```
有效数据带宽 = lane 速率 × lane 数 × 编码效率
```

**编码效率是那个容易漏掉的因子**：早期高速链路需要额外的编码开销来保证时钟恢复，后来的代际大幅降低了这个开销。**所以"每 lane 速率提升"与"带宽提升"不是同一件事**，跨代际比较时必须问清编码方式。

**一个实用的检查**：拿到"链路速率"和"有效带宽"两个数字，**自己除一下**，看编码效率是否落在该代际的已知区间。对不上，说明其中一个数字口径不对。

### 3.2 误码率与链路预算

| 指标 | 含义 |
|---|---|
| **BER（误码率）** | 每传输多少比特出一个错 |
| **链路预算** | 从发送到接收，信号强度与余量够不够 |
| **FEC 开销** | 为纠错消耗的带宽比例 |
| **重传率** | 需要重发的比例（决定平均延迟是否被拖累） |

**这组指标的关键不在数字本身，而在"错误恢复方式"**（见 [00 的第三节](00-物理与工艺.md)）：

```
用 FEC      → 延迟稳定，但常驻带宽开销
用重传      → 无带宽开销，但延迟分布有长尾
```

**所以评估互联时该问的是**：误码率量级是多少、用什么机制恢复、以及**这个机制在目标负载下会不会造成延迟长尾**。只看峰值带宽会漏掉这个问题。

### 3.3 距离：一个硬约束

**链路速率与可达距离是一对矛盾**（速率越高，铜上衰减越快）。所以工程上的判断很直接：

```
在给定速率下：
  需要传输的距离 ≤ 该介质/该速率下的可达距离？
    是 → 可行
    否 → 换介质（铜→光）、降速率、或增加中继
```

**这就是"机柜内铜、跨机柜光"的定量形式**，也是超节点把距离压到最短的根本动机——**不是为了便宜，而是为了在需要的速率下还能跑得动**。

## 四、供电与散热指标：决定系统形态

### 4.1 供电

| 指标 | 含义 |
|---|---|
| **供电电流与电压** | 大电流低压是现代加速卡的常态 |
| **瞬态响应** | 负载剧变时电压能多快稳住 |
| **供电阻抗** | 从电源到芯片的路径阻抗（越低越好） |
| **供电规格标准** | 连接器与线缆能承载多少功率 |

**为什么这项在系统层很重要**：**供电能力直接限制单卡功率上限，而单卡功率上限又限制算力**。所以"同样芯片不同板卡性能不同"往往不是芯片问题，而是供电与散热设计不同。

### 4.2 散热与 TDP

| 指标 | 含义 |
|---|---|
| **散热能力** | 单位时间能带走多少热量 |
| **功率密度** | 单位体积/单位面积的功率（决定风冷还是液冷） |
| **TDP** | **散热设计目标**，不是功耗上限（见下） |
| **机房功率密度上限** | 机柜/机房能提供多少电与多少散热 |

**关键判断链**：

```
功率密度 → 决定冷却方式（风冷有物理上限）
冷却方式 → 决定机柜能装多少卡
机柜功率 → 决定机房是否需要改造（配电、承重、管路）
```

**这条链的每一环都可能成为部署瓶颈**，而且**都是钱**。所以在 [L7 的成本核算](../L7-分布式与集群/01-集群评测.md)里，只看卡价会严重低估 TCO——**机房改造的成本常常与硬件同量级**。

### 4.3 TDP 作为指标怎么用

> **TDP 的定义与常见误解见 [00 的 6.3 节](00-物理与工艺.md)**——这里只讲"作为指标怎么用"，避免两处重复。

| 用法 | 说明 |
|---|---|
| **正确地用** | 作为**规划散热与配电的输入**——它是设计目标，不是实测值 |
| **错误地用** | 当作**实时功耗上限**去估电费。官方明确说加速与特定指令负载下**可短时超过它** |
| **必须问清的** | 这个数字指的是**芯片、板卡还是整机**？三者在不同厂商语境下常被混用 |

**报告功耗时的纪律**：**不要只给一个数字**。至少要区分"设计目标（TDP 类）"与"实测功耗（某负载点下）"，并说明是哪一级（芯片/板卡/整机）——否则这个数字无法用于任何核算。

## 五、成本指标：这一层的终极输出

前面所有物理指标最终都折算成钱。有几个口径要分清：

| 指标 | 含义 | 陷阱 |
|---|---|---|
| **每片晶圆成本** | 晶圆单价 | 与最终芯片成本差一个良率因子 |
| **每颗好芯片成本** | 晶圆成本 ÷（每片芯片数 × 良率） | **必须带良率**，否则低估 |
| **每 GB 存储成本** | 容量单价 | 要区分标称与可用容量 |
| **每瓦散热成本** | 带走一瓦热量的开销 | 常被完全忽略 |
| **每单位带宽成本** | 互联的性价比 | 跨层级（片内/D2D/卡间/跨机）差异巨大 |

**一个反直觉但重要的结论**：**成本最优的产品往往不是性能最高的产品**——因为良率与封装成本会惩罚"越大越强"的设计。这也解释了为什么同一代技术会同时存在"小芯片拼装"和"单大芯片"两种产品线：**它们服务的是不同的成本敏感度**。

## 六、怎么评估才算可信

**必须固定的**：工艺与代际（而不是节点名）、封装方案、链路代际与编码方式、散热条件与环境温度。

**必须报告的**：良率假设（缺陷密度、模型、聚集因子）、是标称容量还是可用容量、以及**功耗是 TDP 还是实测**。

**这一层特有的坑**：

- **用节点名比较工艺**：不同厂商的"3nm"不可比。
- **良率算成本时漏掉良率项**：只算"晶圆成本 ÷ 芯片数"会严重低估。
- **芯粒只算芯粒良率、不算封装良率**：漏掉"各芯粒良率之积"这个乘法效应。
- **用信号速率当数据带宽**：漏掉编码效率。
- **忽略错误恢复机制对延迟分布的影响**：只看峰值带宽会漏掉长尾。
- **把 TDP 当实际功耗**：电费与散热规划都会偏。
- **只算卡价、不算机房改造**：TCO 会严重低估。
- **忽略先进封装产能**：交付能力可能不取决于晶圆，而取决于封装。

## 七、一张表：该看哪个指标

| 你要回答的问题 | 该看的指标 |
|---|---|
| 这个工艺值不值得上 | 晶体管密度 + **SRAM 位单元面积** + 目标功耗下的性能（不是节点名） |
| 芯片要拆成芯粒吗 | 良率公式（面积效应）vs 封装与测试成本 |
| 综合良率大概多少 | 各芯粒良率之积 × 封装良率（注意乘法效应） |
| 链路实际能跑多少带宽 | lane 速率 × lane 数 × **编码效率**（不要漏第三项） |
| 链路延迟稳不稳定 | 误码率 + 恢复机制（FEC 还是重传）+ 重传率 |
| 这个速率能传多远 | 介质与速率下的可达距离（决定铜还是光） |
| 系统装得下吗 | 功率密度 → 冷却方式 → 机柜密度 → 机房改造需求 |
| 真实成本是多少 | 每颗好芯片成本（含良率）+ 每 GB/每瓦/每单位带宽成本 |
| 能不能交付 | 先进封装产能与测试覆盖率（常是真正瓶颈） |
